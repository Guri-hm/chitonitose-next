## 天平文化

### ２つの歴史書

#### 歴史書①

:::top
６世紀、「帝紀」（大王の系譜）・「旧辞」（朝廷の伝承）が編纂されたと考えられます。
:::

:::last
天武天皇は、豪族のもつ「帝紀」「旧辞」の写本に誤りが多く、また、不必要な部分を削って一書にまとめるべきとし、訂正・集成に臨みました。
:::

:::sup
写本の過程での誤りに加え、「帝紀」「旧辞」は難解で誤読も多発
:::

::arrow

:::top
712年、『古事記』
:::lead
元明天皇の命令で、[[<ruby>稗田阿礼<rt>ひえだのあれ</rt></ruby>]]が「帝紀」「旧辞」の内容を正しく<ruby>誦習<rt>しょうしゅう</rt></ruby>し、それを[[<ruby>太安万侶<rt>おおのやすまろ</rt></ruby>]]が整理しながら漢字で筆録物語的要素が強く、神話・伝承も含んだ、天皇家による国土統治の歴史書
:::

:::sup
誦習
:::lead
難解な史料を読み解くこと

### 地誌

:::top
713年、諸国の国司に、国の地誌『[[<ruby>風土記<rt>ふどき</rt></ruby>]]』の編纂が命じられました。
:::

:::last
国司は、国内の地名とその由来・動植物・伝承をまとめました。
:::

### 漢詩

:::top
漢文でやりとりされる律令体制では、貴族・官吏に漢文の学習が求められました。
:::

:::last
そのため、漢詩をたしなむことが貴族・官吏の間で流行しました。
:::

#### 漢詩文集

:::top
751年、『懐風藻』
:::lead
７世紀後半の漢詩を収めた、==勅撰ではない==最古の漢詩文集
:::

### 和歌

:::top
『万葉集』
:::lead
８世紀半ばまでの和歌を収めた、==勅撰ではない==最古の和歌集東国（三河以東）から集められた[[<ruby>東歌<rt>あずまうた</rt></ruby>]]、兵役で九州に向かう<ruby>防人<rt>さきもり</rt></ruby>が詠んだ[[防人歌]]など、作者不明とされる下級官人・庶民の和歌も多く収録
:::

### 教育制度

:::top
教育機関は律令に従って整えられ、次の２種類に大別できます。
:::

- 大学
  :::lead
  式部省の管轄下で、==中央（都）に==置かれた教育機関
  :::
  :::lead
  一定以上の位階の者の子弟が優先して入学
  :::
- 国学
  :::lead
  国司の管轄下で、==地方（国）に==置かれた教育機関
  :::
  :::lead
  郡司の子弟が優先して入学
  :::

::arrow

:::top
教科には、例えば次の３種類がありました。
:::

- 明経道
  :::lead
  五経や『論語』などの儒教の経典を学ぶ教科
  :::
- 明法道
  :::lead
  律令などの法律を学ぶ教科
  :::
- 紀伝道
  :::lead
  漢詩・歴史を学ぶ教科（９世紀に重視）
  :::

:::last
これらの教科の修了後には位階がもらえました。
:::

  :::last

## 室町文化

### ３つの時期区分

- 南北朝文化
  :::lead
  時期は主に南北朝時代にあたり、動乱の緊張感を背景に歴史書や軍記物語が盛んに作られた文化
  :::
- 北山文化
  :::lead
  時期は14世紀末から15世紀前半にあたり、公家・武家の文化融合が進み、禅宗など中国の文化も受けた文化

  :::sup

### 鎌倉仏教の動向

#### 世俗を嫌った禅宗の一派

:::top

:::last

:::

:::last
==臨済宗==大徳寺の僧[[一休宗純]]は、五山の腐敗や堕落を批判しました。
