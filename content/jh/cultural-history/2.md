### 絵画

:::top
城郭建築の内部は、権威を視覚的に高めるために装飾されました。
:::

:::middle

:::middle

:::lead

:::last

## 寛永期の文化

### 朱子学の受容

:::top
安土・桃山時代から江戸時代初頭、禅僧であった[[藤原<ruby>惺窩<rt>せいか</rt></ruby>]]が、朱子学の教育に努めました。
:::

:::middle
江戸幕府・諸藩は、現状の秩序維持を目的に朱子学の受容を決めました。
:::

:::middle
藤原惺窩に推挙されたことで、その門人[[林<ruby>羅山<rt>らざん</rt></ruby>]]は徳川家康に用いられ、秀忠・家光・家綱と４代の<ruby>侍講<rt>じこう</rt></ruby>を務めました。
:::

:::middle
林羅山は幕府の命で、子の<ruby>鵞峰<rt>がほう</rt></ruby>とともに歴史書『[[本朝<ruby>通鑑<rt>つがん</rt></ruby>]]』を完成させました。
:::

:::last
林羅山の子孫は[[林家]]と呼ばれ、彼の子孫は代々儒者として幕府に仕えました。
:::

### 尊王論

:::top
幕藩体制の中の天皇を王者として尊ぶ思想を[[<ruby>尊王<rt>そんのう</rt></ruby>論]]と呼びます。
:::

:::middle
尊王論は元来「朝廷を尊ぶことで、天皇の委任で政権を預かる将軍・幕府の権威を守ろう」という思想だが、後に「“王者”の天皇が“覇者（武力での支配者）”の将軍に勝る」という尊王斥覇に変質し、討幕に繋がりました。
:::

:::last
水戸藩の『[[大日本史]]』編纂事業を通して興った学問[[水戸学]]は尊王論が強く、朱子学を軸に国学・神道を総合して天皇尊崇と秩序の確立を説き、尊王斥覇の考えが主流でした。
:::

### 方針違反への対応

:::top
幕府は、蘭学に対する方針（成果の機密・民間研究の禁止）違反に次の弾圧をしました。
:::

- 1828年、シーボルト事件
  :::lead
  [[シーボルト]]の帰国時、「大日本沿海<ruby>輿地<rt>よち</rt></ruby>全図」などの国外持出が発覚した事件
  :::
  :::lead
  文献を得るためにシーボルトに地図を贈った天文方の[[高橋景保]]は死罪
  :::
  :::sup
  シーボルト…国外追放後、『日本』を著して西洋に日本を紹介
  :::
- 1839年、蛮社の獄
  :::lead
  1837年の[[モリソン号事件]]や幕府の対外政策への批判を理由に、蘭学を私的に研究していた[[渡辺崋山]]・[[高野長英]]を処罰した事件
  :::
  :::lead
  見せしめが目的で、蘭学を学んで幕政批判に傾かないように警告
  :::
