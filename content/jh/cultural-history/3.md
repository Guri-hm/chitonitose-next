## 文明開化

### 思想

:::top
儒学・神道の考え方や慣習が排斥され、自由主義・個人主義などの西洋思想が流入しました。
:::

:::last
人は生まれながらに自由・平等で、幸福追求の権利をもつという[[<ruby>天賦<rt>てんぷ</rt></ruby>人権]]思想は、後の自由民権運動にも大きな影響を与えました。
:::

### 教育

:::top
1871年、文部省が新設され、教育・学芸関連を司りました。
:::

:::middle
1872年、==フランスに倣った==学校制度の法令[[学制]]を公布し、序文「<ruby>被仰出書<rt>おおせいだされしょ</rt></ruby>」で「学問は身を立てる財本」と立身出世主義を強調しました。
:::

:::last
全国を大・中・小の３段階の学区に分け、小学区に初等教育機関[[小学校]]を置きました。
:::

#### 神道の純化と国教化

:::top

## 明治の文化

### 思想

#### 西洋文化と日本文化

:::top
条約改正を目的に、1882年から外相[[井上<ruby>馨<rt>かおる</rt></ruby>]]の[[欧化]]政策が始まり、また、欧化政策を肯定する思想[[欧化]]主義も生じました。
:::

:::last
鹿鳴館外交に代表される極端で上からの欧化政策は、激しい反発を招きました。
:::

:::gazo
![](/images/jh/img/133/1.jpg)

鹿鳴館外交

:::top

:::lead

### 信教

#### 神道

:::top
明治時代初め、新政府は神道の国教化を試みましたが、十分な成果をあげられませんでした。
:::

:::last
一方、政府の公認を受けた民間の神道[[教派神道]]は、庶民の間にかなり広まりました。
:::

#### 仏教

:::top
1868年、神仏分離令制定
:::lead
神道の国教化を前提として、神道の純化のために神仏習合を禁じた法令堕落した僧侶への怒りから、仏教を排斥する行動[[<ruby>廃仏毀釈<rt>はいぶつきしゃく</rt></ruby>]]が全国で発生
:::

::arrow

:::top
仏教の勢力は廃仏毀釈で弱まりましたが、[[<ruby>島地黙雷<rt>しまじもくらい</rt></ruby>]]のように信教の自由を説く者の活躍で、次第に勢力を回復していきました。
:::

#### キリスト教

:::top
次の外国人教師、<ruby>所謂<rt>いわゆる</rt></ruby>[[お雇い外国人]]の影響で、キリスト教が知識人に広まりました。
:::

:::list{class="en"}
- ヘボン：日本語のローマ字表記方法の考案、日本初の和英辞典を編纂した宣教師
- クラーク：札幌農学校で教鞭をとった人物
- ジェーンズ：
               熊本洋学校で教鞭をとり、生徒がキリスト教徒の団体「熊本バンド」を結成したため解任された人物
:::

:::middle
日本人の信徒のなかからは、札幌農学校で学んだ内村鑑三・新渡戸稲造や、熊本バンドに参加した[[海老名弾正]]が現れ、人々の心をとらえました。
:::

:::last
キリスト教会は、売春廃止に取り組む運動<ruby>廃娼<rt>はいしょう</rt></ruby>運動をおこないました。
:::

## 戦時下の文化

### 文学界の変化

#### 昭和初期

:::top
次の文学が、昭和初期の文学界の二大潮流でした。
:::

- プロレタリア文学
  :::lead
  社会主義の立場から労働者の姿を描く作品
  :::
- 新感覚派
  :::lead
  反自然主義の立場の文学で、特に感覚的表現を重視した一派
  :::
  :::lead
  横光<ruby>利一<rt>りいち</rt></ruby>の『日輪』、[[<ruby>川端康成<rt>かわばたやすなり</rt></ruby>]]の『[[<ruby>伊豆<rt>いず</rt></ruby>の踊子]]』
  :::

#### 日中戦争の開戦後

:::top
1930年代前半の社会主義の弾圧でプロレタリア文学は壊滅していき、また、日中戦争が開戦したことで、文学界には次のような文学が現れました。
:::

::arrow

:::top
戦争文学
:::lead
従軍体験など戦争を主題とする作品従軍体験を記録した[[<ruby>火野葦平<rt>ひのあしへい</rt></ruby>]]の『[[麦と兵隊]]』、兵士の実態を描き==発禁となった==[[石川<ruby>達三<rt>たつぞう</rt></ruby>]]の『[[生きてゐる兵隊]]』
:::

:::gazo{size="half"}
![](/images/jh/img/154/3.jpg)

『麦と兵隊』
:::

:::gazo{size="half"}
![](/images/jh/img/154/4.jpg)

石川達三
:::

::arrow

:::top
文学活動による戦争協力をおこなう国策的文学者団体[[日本文学報国会]]や、徳富蘇峰を会長とした文化人の国策協力団体[[大日本言論報国会]]が結成されました。
:::
