::top

### 地域ごとの気候区分
#### 朝鮮半島北部
::top
緯度が高いため最寒月平均気温が低く、冬に北西季節風の影響で少雨になります。
::
::last
[[亜寒帯冬季少雨]]気候（[[Dw]]）が分布します。
::
#### 朝鮮半島南部
::top
北部と同様に冬に北西季節風の影響で少雨になりますが、緯度が低いため最寒月平均気温が高いです。
::
::last
[[温暖冬季少雨]]気候（[[Cw]]）が分布します。
::
---arrow---
::top
対馬海峡付近は、暖流の対馬海流の影響で暖かく、１年を通して降水があります。
::
::last
[[温暖湿潤]]気候（[[Cfa]]）が分布します。
::

::top
韓国の人口密度は、世界有数の高さです。
::

::top

::
::middle

### 工業
#### 漢江の奇跡
::top
1960年代まで、韓国の工業は、衣料や食品などの軽工業が中心でした。
::
::middle
1970年代、韓国は日本の援助を得て、鉄鋼・造船・自動車などの重化学工業を発展させました。
::
::last
この時期の韓国の急速な成長は、「{{漢江|ハンガン}}の奇跡」と呼ばれています。
