::top

::
::last

#### 島嶼
::top

::
::middle

::middle

::
::last
また、サンゴ礁の島は地球温暖化によってサンゴ礁の白化現象（劣化すること）や沈むことが危惧されています。

### サンゴ礁
::top

::
::last
そのため==サンゴ礁は寒流の流れる地域に分布しにくいと言えます==。

### 地域ごとの気候区分
#### 南回帰線付近
::top
一年を通して[[中緯度高圧]]（[[亜熱帯高圧]]）帯の影響を受け、乾燥気候（BW）・ステップ気候（BS）が分布
::
::sup
南回帰線はオーストラリア大陸のほぼ中央を横断
::
#### オーストラリア大陸北部
::top
冬季に北上した[[中緯度高圧]]（[[亜熱帯高圧]]）帯の影響を受け、サバナ気候（AW）が分布
::
#### オーストラリア大陸南西部
::top
夏季に南下した[[中緯度高圧]]（[[亜熱帯高圧]]）帯の影響を受け、地中海性気候（Cs）が分布
::
#### オーストラリア大陸東部とニュージーランド
::top
東部沿岸を流れる[[暖]]流の東オーストラリア海流の影響を受け、温暖湿潤気候（Cfa）・西岸海洋性気候（Cfb）が分布
::
::last
特にニュージーランドは、暖流に加えて偏西風の影響も大きく、年間を通じて湿潤になり、西岸海洋性気候（Cfb）が分布
::
::gazo
![](Oceania_Cf.webp){.border}
Cfa・Cfbの地域

#### 地域ごとの農業
<h5 id="great_artesian_basin">グレートアーテジアン盆地（大鑽井盆地）</h5>
::top
グレートディバイディング山脈の山麓では、山地の雨水が水を通しにくい地層の底に溜まっています。
::
::middle
地層が掘り抜いた井戸で水（被圧地下水）を得ます。
::
::middle
この水は塩分濃度が高く、灌漑用途や人の飲み水には不向きです。
::
::last
主に[[メリノ]]種の羊を放牧します。
::

::top

<h6>マリーダーリング盆地</h6>
::top
オーストラリア南東部には、マリー川とダーリング川が流れます。
::
::last
２つの河川に名前が由来するマリーダーリング盆地は、内陸に位置するため降水量が多くありません
::
---arrow---
::top
オーストラリアアルプス山脈（グレートディバイディング山脈の南部）の東側は降水量が多いため、川の水をせき止め、西側のマリー川に導水しました。
::
::middle
この導水で水力発電や灌漑農業をおこなう一大計画をスノーウィーマウンテンズ計画と呼んでいます。
::
::last
マリーダーリング盆地で灌漑農業がおこなえるようになりましたが、マリー川流域で塩害が深刻化しました。
::
::gazo
