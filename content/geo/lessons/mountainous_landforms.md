## 山地・山脈
### 褶曲山脈
::top
地殻内の圧力によって地層が波状に曲がることを{{褶曲|しゅうきょく}}と呼びます。
::
::last
褶曲した地層で形成された山脈を褶曲山脈と呼び、アルプス山脈やヒマラヤ山脈などの[[新期]]造山帯の山脈が該当します。
::
::gazo
![](folded_mountains.webp)
褶曲の図解
::
::gazo
![](syukyoku.webp)
褶曲
::
### 断層
::top
圧力が加わったことによる地盤の割れ目を断層と呼びます。
::
::last
断層にさらに圧力がかかり、割れ目にずれが生じます。
::
::gazo
![](normal_fault.webp)
正断層型
::
::gazo
![](reverse_fault.webp)

::
::gazo
![](Appalachian_fault.webp)

::

:::lead

:::
:::lead
断層山地のうち、片側のみが断層崖である山地を傾動山地と呼称
:::</li>
<li>地溝（断層盆地）:::lead
両側を断層崖にはさまれた低地
:::</li>
</ul>

## 火山
### 火山の形成
::top
火山は、地中のマグマが地表に噴出して形成されます。
::
::last
マグマが地表へ噴出する理由は、狭まる境界や広がる境界で異なります。
::
::sup
マグマ<div class="lead">マントルの一部が融解したもの
::
</div>
#### 狭まる境界
<h5>海洋上の狭まる境界</h5>
::top
海洋上の狭まる境界では、沈み込むプレートが海水を運び、マントルの融点が下がってマグマが形成されます。
::
::middle
マグマが形成される位置は、海溝が形成される位置よりも、さらにプレートが沈み込んだ先です。
::
::last
そのため、マグマが噴出して火山が形成される位置は、海溝と<span onclick="choice(this)" class="choice"><span
        class="false_choice">重なります</span>/<span class="true_choice">重なりません</span></span>。
::
---arrow---
::top
海溝に沿って形成された火山のうち、最も海溝側に近いもの同士を結んだ線を[[火山前線]]（[[火山フロント]]）<a href="geo_lessons_jp_terrain.html#volcano_formation"
      class="link-active link-icon"></a>と呼びます。
::
::gazo
![](volcano_formation.svg)
海洋上の狭まる境界
::
<h5>大陸上の狭まる境界</h5>
::top
大陸上の狭まる境界では、マグマが地表へ噴出しないため、火山が<span onclick="choice(this)" class="choice"><span
        class="false_choice">分布します</span>/<span class="true_choice">分布しません</span></span>。
::
#### 広がる境界
<h5>海洋上の広がる境界</h5>
::top
海洋上の広がる境界では、海底に山脈が形成されます。
::
::last
これを[[海嶺]]と呼び、一部には火山（海底火山）が分布します。
::
::gazo
![](hirogaru_kairei.svg)
海洋上の広がる境界
::
<h5>大陸上の広がる境界</h5>
::top
大陸上の広がる境界では、火山が形成されます。
::
::gazo
![](hirogaru_chiko.svg)
陸上の広がる境界
::
#### ずれる境界
::top
ずれる境界では、マグマが地表へ噴出しないため、火山が<span onclick="choice(this)" class="choice"><span
        class="false_choice">分布します</span>/<span class="true_choice">分布しません</span></span>。
::

<div class="top" id="hotspot">地球上には、プレートの境界以外にも、局所的に地下深くのマントルがマグマとなって上昇する場所が存在します。</div>

::last

::
::last

#### 注意が必要な場所
<h5>ヒマラヤ山脈</h5>
::top
ヒマラヤ山脈は、大陸プレートと大陸プレートの狭まる境界で形成された褶曲山脈です。
::
::last
新期造山帯に属し、地震が発生する変動帯に位置しますが、火山は分布しません。
::
<h5>デカン高原</h5>
::top
インドのデカン高原は、玄武岩質の溶岩台地（大量の溶岩流で形成された平らな台地）です。
::
::last
ただし、現在のデカン高原に火山は分布しません。<a href="geo_lessons_South_Asia.html#Himalaya_formation"
      class="link-active link-icon"></a>
::
::gazo
