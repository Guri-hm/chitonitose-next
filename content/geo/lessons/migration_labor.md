## 国際的な人口移動
### 移民の呼称
::top
歴史のなかで人々は様々な理由で外国に移住しました。
::
::last
外国に移住した人々には、次のような呼称があります。
::
<ul class="en">
<li>華僑:::lead
中国からの移民で、中国国籍を保有
:::
:::lead
現地の国籍を取得した場合は[[華人]]と呼称
:::</li>
<li>印僑:::lead
イギリス植民地時代のインドからの移民
:::</li>
<li>[[ガストアルバイター]]
:::lead
1960年代、ドイツが労働者不足を補うために協定を結び、[[トルコ]]から受け入れた外国人労働者
:::
:::lead
「一時的な労働者」という扱いで、いずれ帰国する存在という扱いだったが、協定停止後も滞在を続けて問題化
:::</li>
<li>日系人
:::lead
日本人の海外移住者の子孫
:::
:::lead
1990年以降、南米の[[ブラジル]]・[[ペルー]]からは雇用を求めた日本への移動が増加
:::</li>
</ul>

## 日本への入国
### 法・制度の改正
::top
1990年、[[入国管理法]]改正<div class="lead">以前は単純労働者の入国・定住を認めなかったが、日系３世まで家族含めて就労可能に変更
::
</div>
---arrow---
::top
南米の[[ブラジル]]・ペルーなどから入国が増加し、輸送用機械の多い東海地方の[[愛知県]]（トヨタ）・[[静岡県]]（ヤマハ・スズキ）、関東地方の神奈川（日産）・群馬県（スバル）に居住しています。
::
---arrow---
::top
1997年、外国人技能実習制度の改正<div class="lead">以前は１年間の「研修」と技術向上の１年間の「特定活動」としていたが、「特定活動」を２年に延長
::
</div>
---arrow---
::top
中国や[[フィリピン]]・ベトナムからの流入が増加しました。
::

## 賃金
### 国民総所得（GNI）
::top
「１人当たりの国民総所得（GNI）」≒「１人当たりの年収」≒「各国の経済水準」と考えます。
::
::last
また、入試においては、他に国民総生産（GNP）、国内総生産（GDP）という表現も出てきますが、国民総所得（GNI）とほぼ同じ意味と考えるとよいです。
::
---arrow---
::top
産業別に国民総所得（GNI）に占める割合を見ると、基本的には==第３次産業＞第２次産業＞第１次産業==となります。
::
::middle
また、経済の発達に伴って第１次産業人口が減少し、第２次・第３次産業人口が増加します。
::
::last
つまり、==先進国ほど国民総所得（GNI）が高くなります。==
::

### 各国のGNI
#### 北欧
::top
人口１人当たりのGNIが高い先進国では、社会保障が充実しています。
::
::last
社会保障が充実する北欧諸国は、やはり表にあるように人口１人当たりのGNIが高いです。
::
#### スイス
::top
スイスは、チューリヒなどに金融・保険業が集積し、金融サービス部門に特化して経済水準が極めて高いです。
::
::last
==人口１人当たりのGNIは、先進国の中でもトップクラスに高いです==。
::
#### 日本
::top
日本の人口１人当たりのGNIは、先進国としてのイメージから高いと思われますが、==スイスの半分以下に過ぎません。==
::
::sup
==入試ではスイスと日本の値のどちらかを覚えておくと応用可==
