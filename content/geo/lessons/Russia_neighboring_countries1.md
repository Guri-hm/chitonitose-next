### ヨーロッパロシアの地形
#### 大地形
::top
ヨーロッパロシアはウラル山脈より西側の地域です。
::
::middle
大部分を安定陸塊が占め、一部に古期造山帯と新期造山帯が分布します。
::
::last
シベリアとの境界であるウラル山脈は、平均標高900m～1200mで[[古期]]造山帯に分類され、黒海からカスピ海まで走るカフカス山脈は、[[新期]]造山帯に分類されます。
::
::sup
ウラル山脈は東経[[60]]度にほぼ一致
::
#### 河川
::top
カスピ海に注ぐヴォルガ川はヨーロッパ最長です。

<h5>タンガニーカ湖</h5>
::top

#### 河川
::top
シベリアや極東ロシアを流れるオビ川・エニセイ川・レナ川などは、冬季に河川が凍結し、流量がほとんどありません。
::
::middle
5～6月頃に緯度が低い上流の氷が融け、流量が急激に増加します。
::
::last
下流がまだ凍結しているところに上流の水が流れ込むため、川の水があふれて洪水が発生します（融雪洪水）。
::

<h5>寒極</h5>
::top
寒極とは、北半球・南半球それぞれで最低気温が観測された地点のことです。
::
::middle
北半球の寒極は極東ロシアのオイミャコンで、1933年に-67.8℃が観測されました。
::
::last
この地は、北極圏に近くて冬季の日照時間が短く、盆地で冷気がとどまるために気温が低くなります。
::
::sup
同地で1926年に観測された-71.2℃という記録は正確性に疑いあり
::
::sup
-67.7℃という数値も散見するが、世界気象機関のデータに準拠
::
::sup
2020年、世界気象機関が北半球の観測史上最低気温をグリーンランドの-69.6℃と発表
::

## 歴史・経済
### 第一次世界大戦後
::top
1922年、15の社会主義国でソビエト連邦（ソ連）を構成しました。
::
::last
ソ連は経済全体を意識的に管理・運営する[[計画]]経済をとりました。
::
::gazo
![](Soviet_Union.webp){.border}
ソビエト連邦の構成国
::
### 第二次世界大戦後
::top
ソ連中心の陣営とアメリカ合衆国中心の陣営が、冷戦と呼ばれる対立状態になりました。
::
::last
ソ連は次第に経済が停滞し、社会主義の限界が露呈しました。
::
### 現代
::top
1991年、バルト三国をはじめソ連の構成国が独立し、ソ連が崩壊しました。
::
::middle
ソ連崩壊のさなか、バルト三国を除く旧ソ連の構成国は、経済・外交を協力する[[独立国家共同体]]（[[CIS]]）を結成しました。
::
::last
かつての構成国は、自由競争で価格や需要供給を調整する[[市場]]経済へ移行しましたが、移行による混乱で経済停滞が続きました。
::
---arrow---
::top
CISからは、ジョージアが2009年に脱退し、ウクライナも脱退手続きをおこなっています。
::
::last
現状のCISは各国の利害が一致せず、形骸化の傾向がみられます。
::
::gazo
![](CIS.webp){.border}
CISの加盟国（結成当初）

<h2 id="agriculture">農業</h2>
### ソ連時代
::top
社会主義体制（計画経済）下、次のような農業の集団化をおこないました。
::
<ul class="en">
<li>コルホーズ:::lead
集団農場の意味で、土地にもともと住む農民たちで農業・漁業などを営む経営形態
:::</li>
<li>ソフホーズ:::lead
国営農場の意味で、国が農民を雇用して耕作させた経営形態
:::</li>
</ul>
::last
いずれの形態でも生産物は国の計画に基づき、生産物は国に引き渡されました。
::
::sup
ソフホーズは「ソ」は「ソ連」のことと覚えると、国営とわかりやすい
::
::sup
ダーチャ<div class="lead">都市住民の多くがもつ、郊外の家庭菜園付きの簡単な別荘
::
<div class="lead">自給用の野菜や果実が栽培されており、社会主義体制時代やその後の混乱期に食料確保の手段として機能</div>
</div>
### 体制移行後
::top
1991年にかけてソ連が崩壊し、構成国は==社会主義体制（計画経済）から資本主義体制（市場経済）に==移行しました。
::
::middle
1990年代の体制が移行した直後は、経済がマイナス成長で国家危機を迎えました。
::
::last
[[2000]]年代に入ると豊富な石油資源を中心に、資源外交を展開し、1人当たり国民総所得（GNI）の数値が急激に上昇しました。
::
