## 地形
::top
北アメリカ大陸は、ヨーロッパから入植したイギリスの主要民族アングロサクソン人が広く開拓したことから、アングロアメリカとも呼ばれます。
::

アングロアメリカの地形

### 大地形
#### 北東部
::top
カナダ楯状地など安定陸塊が広く分布します。
::
::last
鉱産資源の[[鉄鉱石]]が産出し、特にラブラドル高原には多く埋蔵されています。
::
#### 東部
::top
[[古期]]造山帯のアパラチア山脈が北東から南西にかけて走ります。
::
::middle
山脈西側で鉱産資源の[[石炭]]が産出します。
::
::middle
なお、アパラチア山脈東側の山麓には、{{滝線|たきせん}}が見られ、水力を利用した製粉や綿工業がかつて盛んでした。
::
::last
フィラデルフィア・ボルティモア・ワシントンD.C.などは、滝線に沿って発達した都市（滝線都市）に起源をもっています。
::
::sup
滝線<div class="lead">急流が一直線上に並んで分布する地形
::
</div>
::gazo
![](fall_line_city.webp){.border}
滝線都市
::
#### 西部
::top
環太平洋造山帯に属する[[新期]]造山帯が分布します。
::
::last
ロッキー山脈など険しい山脈が太平洋海岸に沿って走るため、アングロアメリカは西高東低の形をしています。
::
#### 中央部
::top
ロッキー山脈東麓は東にかけて緩傾斜の大平原が広がり、グレートプレーンズと呼ばれています。
::
::last
グレーンプレーンズを過ぎ、降水量が多い地域に入ると温帯草原のプレーリーが広がります。
::
#### 西高東低

### 河川
#### ミシシッピ川
::top
長い流域に大規模な構造平野が形成され、河口には{{鳥趾状|ちょうしじょう}}三角州が発達しています。
::
::sup
ミシシッピ川の河口がほぼ西経90度、北緯30度と覚えておくと、地図の位置関係の把握に役立つ
::
::gazo
![](Mississippi_River.webp){.border}
ミシシッピ川の河口
::
#### セントローレンス川
::top
五大湖の１つスペリオル湖から流出し、大西洋に注ぐ川です。
::
::last
カナダとアメリカ合衆国の国境の一部をなし、河口には[[エスチュアリー]]<a href="geo_lessons_coastal_terrain.html#estuary" class="link-active link-icon"></a>が発達しています。
::
#### コロンビア川
::top
アメリカ合衆国北西部の太平洋に注ぐ河川です。
::
::last
ダムが建設され、水力発電・灌漑に利用されています。
::
#### コロラド川
::top
アメリカ合衆国北西部、ロッキー山脈からカリフォルニア湾に注ぐ河川です。
::
::middle
侵食で大峡谷のグランドキャニオンを形成しています。
::
::last
==総合地域開発としてフーバーダムが建設され、水力発電・灌漑に利用されています。==
::

### カナダ・アラスカ州（アメリカ合衆国）
::top
アングロアメリカのうち、北緯40～50度より北側は亜寒帯湿潤気候（Df）が広がります。
::
::last
北極海沿岸には、ツンドラ気候（ET）が分布します。
::
### アメリカ合衆国
::top
アングロアメリカのうち、アメリカ合衆国の西経100度付近は、年降水量500mmです。
::
#### 西経100度西側
::top
太平洋側の山脈に遮られて乾燥します。
::
::last
ロッキー山脈東麓は東にかけて緩傾斜の大平原が広がり、グレートプレーンズと呼ばれています。
::
#### 西経100度東側
::top
温帯草原のプレーリーが広がります。
::
::last
肥沃なプレーリー土が分布します。

### アングロアメリカ西岸
#### アラスカ湾岸～カナダ西岸
::top
亜寒帯海流は、西経150度付近で、北流するアラスカ海流と南流するカリフォルニア海流に分かれます。
::
::middle
アラスカ湾岸～カナダ西岸は、暖流のアラスカ海流と偏西風の影響で高緯度でもそれほど冷え込まず、気温の年較差が小さくなります。
::
::last
西岸海洋性気候、もしくは統計データによって地中海性気候になります。
::
::gazo
![](Anglo_America_Cfb.webp){.border}
アングロアメリカのCfbの分布
::
::top
カナダ西岸の都市バンクーバーと東岸の都市セントジョンズの雨温図を比較すると、暖流の影響がよくわかります。
::
::sup
各都市の位置はページの下方で確認<a href="#city" class="link-active link-icon"></a>

#### カリフォルニア州（アメリカ合衆国）
::top
アメリカ合衆国西岸は、寒流のカリフォルニア海流が南下するため、上昇気流の発生が弱く、夏場もやや涼しい気候になります。
::
::middle
さらにカリフォルニア州付近は、夏季に中緯度高圧帯に覆われて乾燥します。
::
::last
結果、夏季がやや涼しい[[地中海性]]気候（[[Cs]]）になります。
::
