</ul>
::sup
マングローブ<div class="lead">熱帯・亜熱帯の海岸・河口の汽水域となる地域に広く分布する植物
::
</div>

<ul class="circle">
<li>熱帯の多雨で土壌侵食や土壌流出</li>

## 大気汚染・酸性雨
### 大気汚染
::top
近年、PM2.5と呼ばれる直径2.5μm以下の微粒子状の大気汚染物質が注目されています。
::
::gazo
![](China_air_pollution.webp)
中国広州の大気汚染
::
### 酸性雨
::top
水素イオン濃度（pH）がpH5.6以下の雨を[[酸性雨]]と言います。
::
### 要因
::top
工場、自動車、[[火力]]発電所などで使用した化石燃料が主な原因です。
::
::middle
燃焼の際に発生した硫黄酸化物（SOx）や窒素酸化物（NOx）は、空を曇らせたり、大気中で亜硫酸や硝酸に変化して酸性雨になります。
::
::last
ほかにも、硫黄酸化物や窒素酸化物は、紫外線と反応して光化学スモッグを発生させます。
::
::gazo
![](MexicoCity.webp)
光化学スモッグで霞む景色（メキシコシティ）
::
### 影響
::top
大気汚染は人の健康を害します。
::
::middle
また、酸性雨は森林の枯死、湖の酸性化による魚の死滅、歴史的建造物や石像の腐食をもたらします。
::
::last
大気汚染のうち、森林の枯死では、ドイツ南西側の[[シュヴァルツバルト]]の被害が有名です。
::
::gazo
![](acid-rain1.webp)
酸性雨で枯れた木々
::
::gazo
![](kamakura.webp)
酸性雨で黒ずんだ鎌倉大仏
::
::gazo
![](dead_fish.webp)
死んでいく魚
::
::top
大気汚染は、以前はヨーロッパ・北アメリカ・日本など先進国の周辺に限られていました。
::
::middle
近年は中国・インドなど発展途上国でも深刻化しています。
::
::middle
大気汚染で厄介なことは、[[偏西]]風の影響で東側の地域にも被害をもたらすことです。
::
::last
これを越境汚染と言い、大気汚染は国内被害で留まりません。
::
### 対策
<ul class="circle">
<li>湖や森林に中和のための[[石灰]]を散布</li>
<li>硫黄酸化物や窒素酸化物の排ガス処理装置の設置</li>
<li>ハイブリッドカー、電気自動車の利用</li>
<li>1979年、ジュネーヴ（長距離越境大気汚染）条約の締結</li>
</ul>
## オゾン層破壊
### オゾン層
::top
オゾン層は、地表から10～50㎞の上空にある気体の層で、太陽からの有害な紫外線を吸収します。
::
::last
南極の上空には、オゾン層が薄くなり、穴（ホール）のように見える場所があります。
::
::last
近年、このオゾンホールの拡大が観測されています（オゾン層の破壊）。
::
::gazo
![](ozonh_illust.webp)
オゾン層の破壊
::
::gazo
![](ozone-hole.webp)
南極のオゾンホール
::
### 要因
::top
スプレーの噴射剤、冷蔵庫、エアコンで使用される[[フロン]]が、オゾン層を破壊します。
::
### 影響
::top
有害な[[紫外線]]の量が増加し、皮膚ガンや白内障など健康被害に繋がります。
::
### 対策
<ul class="circle">
<li>1985年、ウィーン条約:::lead
オゾン層保護の国際的取り組みを採択
:::</li>
<li>1987年、モントリオール議定書:::lead
特定フロン（フロンのうちオゾン層破壊に繋がるフロン）などの規制
:::</li>
</ul>
## 地球温暖化
### 地球温暖化
::top
長い歴史のなかで地球の平均気温は変動を続けてきました。
::
::last
1980年以降は地球の平均気温が急激に上昇しており（地球温暖化）、21世紀末には最高６℃以上上昇すると予測されています。
::
::gazo
![](global_warming.webp)
地球温暖化
::
### 要因
::top
==二酸化炭素==・メタン・フロンなどの[[温室効果]]ガスが原因と言われています。
::
::gazo
![](greenhouse_effect_gas.webp)
温室効果ガス
::
### 影響
<ul class="circle">
<li>海面の上昇による浸水被害がサンゴ礁の島国や低湿地の国で発生
:::lead
インド洋の[[モルディブ]]、ガンジス川の三角州（ガンジスデルタ）に位置する[[バングラデシュ]]、==ポルダー==と呼ばれる干拓地がある[[オランダ]]が該当
:::</li>
<li>気候変動による砂漠化</li>
<li>生態系の破壊</li>
<li>マラリアなどの病気を伝える蚊の生息域拡大</li>
</ul>
::gazo
![](sea01.webp)
高潮で冠水道路（マーシャル諸島）

（http://www.jccca.org/)」
::
::gazo
![](sea17.webp)
高潮で冠水道路（マーシャル諸島）

<ul class="en">
<li>1992年、国連環境開発会議（別称：地球サミット）での[[気候変動枠組]]条約採択</li>
<li>1997年、[[京都議定書]]採択:::lead
先進国全体で温室効果ガスの排出を削減
:::
:::lead
2001年に[[アメリカ]]が離脱
:::</li>
<li>2015年、==パリ協定==採択:::lead
==途上国を含む全ての参加国と地域に==温室効果ガスの排出削減の目標を設定
:::</li>
<li>[[環境税]]の導入
…二酸化炭素などの排出に対する課税（オランダ、スウェーデンでは既に導入）</li>
</ul>

## 日本の環境問題
### 公害
::top
公害とは、経済的利益を追求した活動で生じる人の健康被害や自然環境の破壊を指します。
::
#### 初の公害事件
::top
[[足尾]]銅山鉱毒事件（場所：[[栃木]]県渡良瀬川中下流域）
::
::gazo
![](ashio.webp)
1895年頃の足尾銅山
::
#### 四大公害病
::top
企業が利益を優先して環境への配慮を怠ったため、次のような公害が発生しました。
::
<ul class="en">
<li>[[水俣病]]（場所：熊本県、原因：有機水銀）</li>
<li>[[四日市ぜんそく]]（場所：三重県、原因：亜硫酸ガス）</li>
<li>[[イタイイタイ病]]（場所：富山県、原因：カドミウム）</li>
<li>[[新潟水俣]]（場所：新潟県、原因：有機水銀）</li>
</ul>
::last
上記の４つの公害は、いずれも原告側が勝利しています。
::
#### 公害からの配慮見直し
::top
1967年、公害対策基本法
::
::top
1993年、[[環境基本法]]
::
::last
これら法では、次の７つが「公害」として定義されています。
::
<ul class="en">
<li>大気汚染</li>
<li>水質汚濁</li>
<li>土壌汚染</li>
<li>地盤沈下</li>
<li>騒音</li>
<li>震動</li>
<li>悪臭</li>
</ul>
### その他の問題
#### 産業廃棄物の問題
::top
産業廃棄物の処分が有料化したことで不法投棄問題が発生しました。
::
::middle
処分を減らし問題をなくすため、循環型社会の実現が目指されています。
::
::last
そのためのキーワードとなるのが3Rと総称される「Reduca（削減）・Reuse（再利用）・Recycle（再生利用）」です。
::
#### 環境ホルモン（内分泌攪乱化学物質）の問題
::top
工業製品、農薬、殺虫剤、プラスチック製品などに含まれる化学物質で、特に体内の正常な働きをするホルモンの働きを破壊し、例えば生殖器の異常などを引き起こすものを環境ホルモンと言います。
::
#### ダイオキシン汚染
::top
ダイオキシンは、農薬の製造や塩化プラスチック系の物質の燃焼で発生する化合物です。
::
::last
発癌性などの毒性が高く、環境汚染による健康や生態系への被害が懸念されています。
::
