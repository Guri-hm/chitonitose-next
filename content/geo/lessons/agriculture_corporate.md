## 企業的農業
### 企業的農業とは
::top
ほぼ商業的農業と同じですが、大資本による大規模な農畜産物の生産をおこない、他国に輸出する企業的農業があります。
::
## 企業的穀物農業
### 成立
::top
産業革命でヨーロッパの諸都市での食料需要が増加し、新大陸からの輸出で需要に応えようとして成立しました。
::
### 特色
::top
企業的穀物農業には次の特色があります。
::
<ul class="en">
<li>[[小麦]]を==商品作物==として単一栽培</li>
<li>粗放的で大規模な経営のため、==低い土地生産性==と==高い労働生産性==</li>
</ul>
::sup

::

## 企業的牧畜業
### 成立
::top
ヨーロッパの諸都市での畜産物需要の増加と、19世紀後半の[[冷凍船]]の発明で成立しました。
::
::gazo
![](reefer-ship.webp)
冷凍船
::
### 特色
::top
新大陸において牧畜をおこない、世界の市場を対象に輸出します。
::
::last
粗放的で、大規模・効率的な経営をおこなうため、[[労働]]生産性は==高くなります==。
::
