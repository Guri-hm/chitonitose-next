## 水産業
### 好漁場の条件
::top
漁場が{{好漁場|こうぎょじょう}}（たくさん獲れる場所）になるためには、いくつかの条件が必要です。
::
#### 自然条件
::top
好漁場の自然条件は、豊富な栄養分と日光があることです。
::
::last
「栄養分→植物性プランクトン→動物性プランクトン→魚類」という食物連鎖を考えれば、植物性プランクトンが必要とする栄養分と光合成のための太陽光が重要だとよく分かります。
::
---arrow---
::top
海中の栄養分は重いため、海底に沈んでいます。
::
::middle
栄養分が、海底から上昇する海水の流れ[[湧昇流]]によって、太陽光の届く浅い水域まで運ばれれば、好漁場が成立します。
::
::last
湧昇流は、次の場所で生じます。
::
<ul class="circle">
<li>[[大陸棚]]
:::lead
大陸の周りを縁取り、水深200ｍ程度までの浅い海域
:::
:::lead
浅い海域までの斜面を伝って海水が上昇しやすく（湧昇流の発生）、加えて大陸棚上では太陽光が海底までよく到達
:::</li>
<li>[[バンク]]（[[{{浅堆|せんたい}}]]）:::lead
大陸棚上で特に水深の浅い部分
:::
:::lead
大陸棚同様の理由で湧昇流が発生し、太陽光も海底までよく到達
:::</li>
<li>[[{{潮境|しおざかい}}]]（[[{{潮目|しおめ}}]]）:::lead
暖流と寒流が出会う海域に生じるもの
:::
:::lead
冷たい寒流が暖かい暖流に出会うと下に潜り込み、渦による海底からの湧昇流が発生
:::</li>
</ul>
::gazo

大陸棚とバンク
::
::gazo
![](oceanic_front.webp){.twice}
潮境（潮目）
::
#### 社会条件
::top
好漁場は、自然条件だけでは成立しません。
::
::last
消費地の存在や食文化などの社会条件も影響しています。
::

### 中国
::top
中国の漁獲量は、1990年代以降に==著しい伸びを示しました==。
::
::middle
今では世界最大の漁獲高になっています。
::
::last
この伸びの背景には、次の３つが挙げられます。
::
<ul class="en">
<li>日本などへの輸出が増加</li>
<li>中国の経済発展によって食生活の水準が向上し、国内需要が増加</li>
<li>湖沼や池などの内水面で営む、コイ科の魚種を中心とした==養殖業==を政府が援助し、多種の淡水魚を生産</li>
</ul>
---arrow---
::top
余談になりますが、中国の漁獲統計の数値は過大に見積もられている疑いがあります。
::
::last
1990年代と2000年代の接合がいったんの減少と増加という不思議なもので、FAOとの見直しで修正作業が入ったものと思われます。
::
::gazo
![](china-aquaculture-industry.jpg)
中国のフナ（コイ科）の養殖
::
### ペルー
<div class="top" id="El_Nino"><span class="marker">ペルー</span>の漁獲量は、<span class="marker">大きく増減しています</span>。</div>
::middle
変動幅が大きいのは、漁獲量の大部分を占める[[アンチョビー]]（カタクチイワシ科）の豊漁不漁によって起こされています。
::
::middle
１種の魚類に依存するため、漁獲量に大きく影響します。
::
::last
このような依存は、1960年代から始まりました。
::
---arrow---
::top
アンチョビーの漁獲量は、えさとなるプランクトンの量を左右する湧昇流にかかっています。
::
::last
1970～1980年代は、湧昇流の発生を弱める[[エルニーニョ]]現象に見舞われ、アンチョビーの不漁となりました。
::

#### 漁業の衰退
::top
日本の水産業は、==養殖を除いて全て漁獲量が減少しています==。
::
<h5>1970年代</h5>
::top
[[遠洋]]漁業は、1973年を最後に激減しています。
::
::last
これは、次の２つを背景に操業可能な漁場が縮小したからです。
::
<ul class="en">
<li>第四次中東戦争に端を発した[[石油危機]]による燃料費の高騰</li>
<li>世界各国による[[排他的経済水域]]（[[200海里経済水域]]）の設定</li>
</ul>
::gazo
![](JP_EEZ.webp){.border}
日本の排他的経済水域
::
<h5>1980年代後半</h5>
::top
遠洋漁業の減少後、[[沖合]]漁業がその減少分を補うように急増しました。
::
::last
しかし、次の２つを背景にこの漁業も減少しました。
::
<ul class="en">
<li>乱獲や海洋環境の変化によるマイワシなどの不漁</li>
<li>国民の嗜好が高級魚に変化</li>
</ul>
::gazo
![](japanese_sardine.webp)
マイワシ
::
<h5>近年</h5>
::top
[[沿岸]]漁業は、沿岸部の埋立ての増加で停滞状態にあります。
::
#### 輸入量の増加
::top
漁業の衰退の一方で、日本の水産物の消費量は増加しています。
::
::last
