## 国家
### 国家とは
::top
日本のような国（国家）は、次の３つをもつ組織です。
::
<ul class="en">
<li>主権:::lead
政治などのあり方に、他国の支配をうけない権力（⇔植民地）
:::</li>
<li>領域:::lead
主権がおよぶ陸地（領地）・海（領海）・空（領空）のこと
:::</li>
<li>人民</li>
</ul>
### 植民地から独立国へ
::top
1900年代半ばまで、世界の半分以上の国が、主権をもたない不完全な状態「植民地」でした。
::
::middle
第二次世界大戦後、1950年代までにアジア諸国が、1960年代にアフリカ諸国が次々と主権を確立し、国として再始動していきました。
::
::last
2002年時点で、世界の国家は196ヵ国にのぼっています（日本と日本が承認している国を合わせて）。
::

### 領土
::top
国の主権が認められる陸地を[[領土]]と言います。
::
::sup
陸地と海の境界は干潮時の海岸線
::
### 領海
::top
国の周辺海域のうち、主権が認められる範囲を[[領海]]、鉱産資源や水産資源の独占が許される範囲を[[排他的経済水域]]（略称：[[EEZ]]）と言います。
::
---arrow---
::top
1982年、国連海洋法条約が調印され、これらの範囲が決まりました。
::
::top
領海：沿岸（最低潮位線）から[[12]]海里以内
::
::top
排他的経済水域：領海を含む[[200]]海里
::
::sup
海里<div class="lead">１海里＝約1.852㎞で、地球１周４万㎞÷360度÷60分（つまり経度１分）から算出
::
</div>

::

<li>==他国は漁船の操業ができない（水産資源の独占）==</li>
</ul>
### 領空
::top
領空は、領土・領海の上空でかつ大気圏内です。
::
## 国境
### 国境とは
::top
国境とは、読んで字の如く主権がおよぶ範囲（＝国）の境界のことです。
::
::last
国境には、次の２つがあります。
::
<ul class="en">
<li>自然的国境:::lead
山脈・河川など自然のものを境界に利用
:::</li>
<li>人為的国境:::lead
人の手による経線・緯線や築造物を境界に利用
:::</li>
</ul>
### 自然的境界
::top
自然的境界は、歴史が長いヨーロッパに多く見られます。
::
::last
例えば、スペインとフランスの境になる[[ピレネー山脈]]、ノルウェーとスウェーデンの境になる[[スカンディナヴィア山脈]]があげられます。

### 人為的国境
::top
人為的国境は、万里の長城などの人工物や経線・緯線を利用した国境です。
::
::middle
現在、人為的国境は経線・緯線を利用した国境（数理的国境）がほとんどです。
::
::last
いずれも一の位まで覚える必要はありませんが、丸めた数値を覚えておき、地図の位置把握に利用しましょう。
::

## 国家群
### 主な国家群
::top
国は、政治や経済、時には軍事の分野で利害が一致する他国と、グループを作ります。
::
::last
このような国々のグループを国家群と呼びます。
::
