## 離水海岸
::top
浅い海底が隆起または海面の低下した海岸を離水海岸と呼びます。
::
::last
離水海岸のうち、平野の場所を海岸平野、段丘の場所を[[海岸段丘]]と区別します。
::
::gazo
![](submergent_emergent_coastline.webp){.twice}
離水海岸・沈水海岸
::
### 海岸平野
::top
代表的な海岸平野は、千葉県東岸の九十九里浜です。
::
::gazo
![](Kujukuri_beach.webp)
九十九里浜
::
### 海岸段丘
::top
海岸段丘の台地面では水が得にくいため、==畑や果樹園に利用==されます。
::
::middle
代表的な海岸段丘は、高知県の{{室戸岬|むろとみさき}}です。
::
::last
なお、海岸段丘は洪積台地の１つです。
::
::gazo
![](coastal_terrace.webp){.twice}
海岸段丘
::
::gazo
![](Murotomisaki.webp)
室戸岬
::
## 沈水海岸
::top
陸地の沈降や海面の上昇した海岸を沈水海岸と呼びます。
::
::gazo
![](submergent_emergent_coastline.webp){.twice}
離水海岸・沈水海岸
::
::top
沈水海岸には、主に次の３つがあります。
::
<ul class="en">
<li>[[リアス海岸]]
:::lead
[[V]]字谷が沈水したのこぎりの歯状の海岸
:::</li>
<li>[[フィヨルド]]
:::lead
氷河によって侵食された[[U]]字谷が沈水した、両側が絶壁の細長い入り江
:::</li>
<li>[[エスチュアリー]]（[[三角江]]）
:::lead
河口の沈水によるラッパ状の入り江
:::</li>
</ul>
### リアス海岸
::top
河川の侵食で形成された谷を[[V字谷]]、<span
			class="marker">氷河による侵食で</span>形成された谷を[[U字谷]]と呼びます。
::
::gazo
![](V_U_shaped_valley.webp)
V字谷・U字谷
::
::top
このうちで、[[V]]字谷が沈水したのこぎりの歯状の海岸を[[リアス海岸]]と呼びます。
::
::middle
語源は、この海岸が見られるスペイン北西の海岸「リアスバハス（リアスバイシャス）」です。
::
::last
リアス海岸は、日本国内でも見られ、三陸海岸（岩手・宮城）、志摩半島（三重）、若狭湾（京都・福井）が代表的です。
::
::gazo
![](V_shaped_valley_submerged.webp)
Ｖ字谷の沈水
::
::top
リアス海岸は、波が遮られて入り江が穏やかになるため、==良港がよく立地します==。
::
::middle
しかし、==地震による津波がひとたび入り江に進入すると、両岸が狭いため、波は一層高くなります==。
::
::last
時には、10階建てのビルも越える高さになります。
::
::gazo
![](rias_bajas.webp){.border}
リアスバハス
::
::gazo
![](rias_coast.webp)
リアス海岸（伊勢）
::
::gazo
![](tsunami_v.webp)
リアス海岸の津波
::

::top
河川の侵食で形成された谷を[[Ｖ字谷]]、<span

![](V_U_shaped_valley.webp)

::
::last
上記以外の場所でも、基本的には==かつて氷河があった高緯度の地域==で見られます。

### エスチュアリー
<div id="estuary" class="top"><span class="marker">土砂の運搬量が少ない</span>河川の河口は、下図のようになります。</div>
::gazo
![](estuary1.svg)
::
::top
このような河口が沈水すると、河口に漏斗やトランペットのような地形が形成されます。
::
::last
この地形を[[エスチュアリー]]（[[三角江]]）と呼びます。
::
::gazo
![](estuary2.svg)
::
#### エスチュアリーの分布
::top
エスチュアリーとして有名なのは、アルゼンチンとウルグアイの間を流れる[[ラプラタ]]川、五大湖からカナダ東部を流れる[[セントローレンス]]川です。
::
::last
ラプラタ川は、大航海時代にマゼラン（生没：1480年頃～1521年）が大きい河口を海峡と誤ったほどです。
::
---arrow---
::top
他のエスチュアリーは、安定陸塊が多く占める==ヨーロッパでよく見られます==。
::
::middle
この理由は、土砂を多く供給する急峻な山地が安定陸塊では少ないためです。
::
::last
代表例は、エルベ川・テムズ川・ジロンド川・セーヌ川などです。
::
::gazo
![](Thames_estuary.webp)
イギリスのテムズ川のエスチュアリー
*GoogleEarthより
::
::top
ただし、エスチュアリーが見られない例外的なヨーロッパの川が、[[ライン]]川です。
::
::middle
それは源流が[[新]]期造山帯に属すアルプス山脈だからです。
::
::last
急峻な山地であるため、土砂の供給が多くなります。
::
::gazo
![](rivers_Europe.webp){.border}
ヨーロッパ中部の河川
::
#### エスチュアリーと産業
::top
エスリュアリーは産業に強く関わります。
::
::last
エスチュアリーは水深が深く、入り江に面して大平野が広がるため、==貿易港や大都市、工業地域が発達します==。
::
## 海岸の微地形
### 微地形の種類
::top
海岸には、沿岸流による堆積で次のような小規模な地形が見られます。
::
<ul class="en">
<li>[[{{砂嘴|さし}}]]
:::lead
沿岸流が運んだ砂が鳥のくちばし（嘴）状に海へ突き出した地形
:::</li>
<li>[[{{砂州|さす}}]]
:::lead
砂嘴が発達して、湾をふさいでいる地形
:::</li>
<li>[[{{陸繋島|りくけいとう}}]]
:::lead
砂州によって繋がった島
:::
:::lead
この島を繋ぐ砂州をトンボロ（陸繋砂州）と呼称
:::</li>
<li>[[潟湖（ラグーン）]]
:::lead
砂州によって外洋から切り離された湖
:::</li>
</ul>

## サンゴ礁
### サンゴ礁の分布
<div class="top" id="coral_reef">サンゴ礁とは、サンゴなど炭酸カルシウムからなる生物の分泌物や遺骸が、海底から発達してできた石灰岩の地形です。</div>
::middle
熱帯から亜熱帯の、水温が==温暖（25～30℃）で==きれいな海の海岸には、サンゴ礁が多く分布します。
::
::middle
そのため==サンゴ礁は寒流の流れる地域に分布しにくいです==。
::
::last
日本では==北緯30度以南==のトカラ列島が北限で、奄美・沖縄と小笠原の島々に限られています。
::
::gazo
![](coral_reef.webp)
サンゴ礁
::
::gazo
![](map_coral_reef.webp){.border}
サンゴ礁の分布
::
### サンゴ礁の発達
::top
サンゴ礁の形態は、島との関係で次の順に変化していきます。
::
<ul class="en">
<li>[[{{裾礁|きょしょう}}]]
:::lead
島の海岸に接して発達したサンゴ礁
:::</li>
<li>[[{{堡礁|ほしょう}}]]
:::lead
島の沈降あるいは海面の上昇で、防波堤のように島を囲んだサンゴ礁
:::</li>
<li>[[{{環礁|かんしょう}}]]
:::lead
島の沈降あるいは海面の上昇で、サンゴ礁のみが環状に残っているもの
:::</li>
</ul>
::gazo
![](coralreef.svg){.twice}
::
