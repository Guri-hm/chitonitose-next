### 大地形
::top
ヨーロッパは、安定陸塊からなる低地が多く、標高200m未満が５割です。
::
::last
南部には新期造山帯に属する山脈が横断し、北部には古期造山帯に属する山脈が分布します。
::
::top

::
</div>
::top
新期造山帯：<div class="top">ピレネー山脈・アルプス山脈など
::
</div>

::top
アイスランドは、[[広がる]]境界上に位置します。

::last

### ヨーロッパ西岸部～中部
::top
ヨーロッパの西側は、[[暖]]流の北大西洋海流が流れ、その上を[[偏西]]風が吹きます。
::
::last
この海流と風の影響を受ける地域では、高緯度でありながら冬場も温暖で、気温の年較差が小さくなります。
::
---arrow---
::top
ヨーロッパは標高200m未満の低地が広がり、南部には東西にアルプス・ヒマラヤ造山帯の山脈が連なります。
::
::last
偏西風が遮られず、山脈に沿うように内陸まで到達します。
::
---arrow---
::top
年間を通して湿潤で、寒すぎず暑すぎない（最寒月平均気温がー３℃を下回らない、最暖月平均気温が22℃を上回らない）、[[西岸海洋性]]気候（[[Cfb]]）が広範囲に分布します。
::
::gazo
![](Europa_Cfb.webp){.border}
ヨーロッパのCfbの分布
::
#### 西岸海洋性気候の分布
::top
偏西風は北アメリカや南アメリカの西岸部にも吹き込みますが、これらの地域にはヨーロッパに比べてCfbがほとんどありません。
::
::last
北アメリカや南アメリカは太平洋に沿って南北に山脈が走るため、偏西風が遮られてしまうからです。
::
::gazo
![](Cfb.webp){.border}
世界のCfbの分布
::
### ヨーロッパ北部
::top
ヨーロッパの北部は、スカンディナヴィア山脈が偏西風や暖流の影響を弱めます。
::
::middle
山脈の風上には南北に[[西岸海洋性]]気候（[[Cfb]]）が、風下には[[亜寒帯湿潤気候]]気候（[[Df]]）が分布します。
::
::last
また、西岸海洋性気候が分布する西部に比べて、気温の年較差が大きくなります。
::
::gazo
![](Europa_Df.webp){.border}
ヨーロッパのDfの分布
::
### ヨーロッパ東部
::top
隔海度が大きくなるほど、偏西風や暖流の影響が及びにくくなります。
::
::middle
結果、ヨーロッパ東部では[[亜寒帯湿潤気候]]気候（[[Df]]）が分布します。
::
::last
この地域では、西岸海洋性気候が分布する西部に比べて、気温の年較差が大きくなります。
::
### ヨーロッパ南部
::top
ヨーロッパ南部は、夏に北上した中緯度高圧帯（亜熱帯高圧帯）の影響で少雨になります。
::

### ベルギーの言語
::top
1830年、カトリック教徒が多いことを理由に、ベルギーがオランダから独立しました。
::
::middle

しかし、次第にオランダ語を反す人々（フラマン地方の人々）が経済的に豊かになり、公用語など諸制度への反発が強まりました。

## 民族問題
### 北アイルラン紛争
::top
イギリスの北アイルランドでは、==多数の==[[プロテスタント]]住民（ゲルマン系）が政権を独占し、==少数の==[[カトリック]]住民（ケルト系）が経済的に貧しい状況に置かれています。
::
::last
カトリック住民は分離独立を要求しています。
::
---arrow---
::top
対立はEUの経済統合で国境が消え、近年融和が進んでいました。
::
::last
しかし、イギリスがEUを脱退したので、対立の再燃が懸念されています。
