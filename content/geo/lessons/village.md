## 集落
### 集落とは
::top
人が集まり居住するところを集落と言います。
::
::last
集落のうち、第１次産業が経済基盤のものを村落、第２・３次産業が経済基盤のものを都市と呼びます。
::
::sup
厳密な区別は国によって異なり、日本では人口規模で区別
::
### 集落の立地
::top
集落の立地には、次の２つの条件があります。
::
<ul class="en">
<li>自然条件:::lead
飲料や農業用の==水が得やすいこと==
:::
:::lead
水害が避けられる==微高地や段丘面であること==
:::</li>
<li>社会条件:::lead
外敵から防御しやすいこと
:::
:::lead
交通の便がよく、物資が入手しやすいこと（==山間部から平野部に出る谷口==など）
:::</li>
</ul>
#### 自然条件
::top
人は水が得やすいところに集まり居住します。
::
::last
特に扇状地では、谷からの水が地下に伏流する前に得やすい[[扇頂]]と、伏流した水が湧出する[[扇端]]に集落が立地します。
::

::top

::

#### 社会条件
::top
人は、その歴史・経済発展のなかで、外敵から防御しやすいところや物資の交換しやすいところに居住しました。
::
::last
山地と平地との物資の交換のために、河川が山地から平地に出る谷口に発達した集落などがあります。
::

### 日本の村落の発達
#### 古代
::top
班田収授法で施行した条里制に基づき、集落が形成されました。
::
::last
その名残が現在の奈良盆地などに見られます。
::
::sup
条里制<div class="lead">碁盤状の田地で、東西の列を「１条、２条、３条…」、南北の列を「１里、２里、３里…」と管理
::
</div>
::gazo
![](../jh/img/15/2.svg)
条里制
::
::gazo
![](Yamato.jpg)
奈良県大和郡山市
＊出典：国土地理院ウェブサイト（<a href="https://maps.gsi.go.jp/#15/34.616822/135.798225/&base=pale&ls=pale&disp=1&vs=c1g1j0h0k0l0u0t0z0r0s0m0f1&d=m">地理院地図</a>）
::
::top
なお、古代の都市である「平城京」「平安京」は唐の長安に倣っており、碁盤上の区画で管理されました。
::
::gazo
![](Heijokyo.jpg)
平城京
::
#### 中世
::top
堺・博多など自治権を獲得した都市が登場しました。
::
#### 近世（江戸時代）
::top
新田開発で新たな村落が成立しました。
::
::last
「新田」「新開」「籠」などを地名に含む場所にその名残が見られます。
::
#### 近代
::top
大規模農業経営が可能な碁盤目状・短冊状の散村が成立しました。
::
::top
例：旭川・札幌などの屯田兵村
::
