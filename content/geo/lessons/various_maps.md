## 地図の大別
### ２種類
::top
地図は大きく２種類に分けられます。
::
<ul class="en">
<li>[[一般図]]
:::lead
特定のテーマを持たず、地形や地名、河川や交通路、集落や行政界などの情報を描いた平均的な地図
:::</li>
<li>[[主題図]]
:::lead
利用目的に応じて、ある特定のテーマの下に重要要素を強調した地図
:::</li>
</ul>
## 一般図
### 実測図
::top
一般図のうち、現地での測量や空中写真測量などをもとに作製した地図を実測図と言います。
::
::gazo
![](25000.jpg)
2.5万分の1地形図
::
### 編集図
::top
実測図をもとに編集し、これを縮小または内容を簡略化して作製した地図を編集図と言います。
::
::last
２万５千分の１地形図４面分を１面にまとめたものが、下図の５万分の１地形図です。
::
::gazo
![](50000.jpg)
5万分の1地形図
::
::gazo
![](50000-2.jpg)
2.5万分の1地形図（赤枠内）との比較
::

![](weather chart.jpg)
天気図

### 統計地図
::top
統計を地図化した主題図を統計地図と言います。
::
::last
地理で扱う統計数値は、大きく次の２つに分かれ、示すのに適した統計地図が異なります。
::
<ul class="en">
<li>絶対的数値:::lead
人口や降水量などの数値
:::</li>
<li>相対的数値:::lead
単位面積あたりの数値（人口密度）や人口１人あたりの数値（所得など）の数値
:::</li>
</ul>
#### ドットマップ
::top
点で一定の数量や分布を表現した地図です。
::
::sup
点は示すものが存在する位置の真上
::
::gazo
![](dot-map.jpg)
アメリカの公共図書館
::
#### 図形表現図
::top
棒の長さ、円の面積などで数量を表す地図で、==絶対的数値（人口・降水量など）を示すのに適切です==。
::
::gazo
![](geometric-symbol-map.jpg)
中部地方の人口密度
::
#### 等値線図
::top
各地点の値をもとに、等しい一定の値の点を求め、それらを曲線で結んだ地図です。
::
::gazo
![](isopleth-map.jpg)
さくらの開花時期
::
#### 流線図
::top
統計事象の移動を図示したもので、矢印の向きで移動の方向を、太さで移動量を示した地図です。
::
::gazo
![](flow-map.jpg)
1864年のフランス産ワイン輸出先
::
#### 階級区分図（コロプレスマップ）
::top
密度や割合等の相対値（単位面積あたり、人口１人あたりなど）をいくつかの階級に区分し、パターンや色で区別した地図です。
::
::last
==相対的数値（人口密度や人口１人あたりの所得など）を示すのに適しますが、絶対的数値（人口や生産量）のように国や地域の面積の大小が統計数値の大小に影響するものでは、実際の分布とは異なる印象を与えるため、この統計地図は不適切です==。
::
::gazo
![](choropleth-map.jpg)
愛知県の人口数
::
#### 変形地図（カルトグラム）
::top
表現する地域・国の形そのものを数量に応じて変形した地図です。
::
::gazo

アメリカの店舗数
::
::gazo
![](cartogram2.jpg)
成人のAIDS患者数
::
