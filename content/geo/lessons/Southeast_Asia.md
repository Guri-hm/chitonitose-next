### プレートの境界
::top
東南アジア付近では４枚のプレートが接します。
::
::last
これらプレートの境界は「狭まる境界」です。
::
---arrow---
::top
境界部分の海底には[[海溝]]が形成されます。<a href="geo_lessons_major_landforms.html#convergent_boundary_ocean" class="link-active link-icon"></a>
::
::middle
海洋側のプレートが沈み込んだ先には、海溝に平行するように弧状列島や火山が形成されます。
::
::last
東南アジアの島嶼部は弧状列島であり、火山が多く分布しています。
::
::sup
==海溝付近には火山が分布しないことに注意==
::
::gazo

#### 自然災害
::top
東南アジアの狭まる境界付近では、地震活動や火山活動が多くなります。
::
::last
近年、次のような自然災害による被災が報道されています。
::
<ul class="en">
<li>2004年、スマトラ島沖地震</li>
<li>2006年、ジャワ島南西沖地震</li>
<li>2020年、フィリピンのタール火山噴火</li>
</ul>
### 海峡
::top
マラッカ海峡は、マレー半島とスマトラ島との間の海峡です。
::
::middle
この海峡は、西アジア（中東）からの原油を日本へ運ぶタンカーが頻繁に往来します。
::
::last
超大型のタンカーは、浅く通行が激しいマラッカ海峡を避け、遠回りのロンボク海峡を通ります。
::
### 三角州
::top
東南アジアの大陸部を流れるエーヤワディー川・チャオプラヤ川・メコン川の河口には、[[三角州]]が形成されています。
::
::sup
メコン川<div class="lead">チベット高原を水源とする国際河川
::
</div>

### 工業化
::top
第二次世界大戦後、東南アジア諸国は工業化に遅れていました。
::
::middle
工業製品の多くを外国から輸入していたため、自国で保有する外貨が流出していました。
::
::middle
そのため、繊維などの軽工業をまずは自国で生産する[[輸入代替型]]の工業化が図られました。
::
::last
しかし、国内市場の規模が小さく、発展には繋がりませんでした。
::
::gazo
![](import_substitution.webp)
輸入代替型
::
---arrow---
::top
1970年代、ASEAN諸国は、輸入代替型の工業化から、[[輸出志向型]]の工業化へ政策を転換しました。
::
::last
市場を外国に求め、輸出向けの製品生産などを目指しました。
::
::gazo
![](export_orientation.webp)
輸出志向型
::
---arrow---
::top
この一環として、雇用機会の増大や技術力の向上などを期待し、免税などの優遇措置を与える地区[[輸出加工区]]を定め、外国企業を誘致しました。
::
::last
代表的な輸出加工区として、シンガポールのジュロン、マレーシアのペナンがあります。
