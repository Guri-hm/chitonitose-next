## 気候と気候要素
### 気候とは
::top
気候とは、長期にわたって毎年繰り返される大気の総合的な状態のことです。
::
::middle
「暑くて夏に雨が多く降る」など、ある地域の性格とも言えます。
::
::last
そして、その性格を説明する際に用いる「暑いのか（気温）」「雨が多く降るのか（降水）」「風がどのように吹くのか（風）」という要素を、気候要素と言います。
::
::gazo
![](climatic_elements.webp)
気候要素
::
### 気候要素
::top
主な気候要素は次の３つです。
::
<ul class="en">
<li>気温</li>
<li>降水</li>
<li>風</li>
</ul>
---arrow---
::top
これら気候要素は、複数の要因に左右されます。
::
::middle
例えば、気候要素の「気温」は、「緯度」「海抜高度」などで「暑い」か「寒い」に分かれます。
::
::last
このような「緯度」「海抜高度」などにあたるものを、気候因子と言います。
::

::
::middle
気温の等しい地点を結んだ線を等温線と呼びます。
::
::last
次の図は上から順に「１月の等温線」「７月の等温線」です。

::gazo
![](isothermal7.webp){.border}

::
::top
等温線は、原則==緯線にほぼ平行になります==。
::
::last
高緯度ほど低い値の等温線が通るため、気温は緯度が高くなるほど<span onclick="choice(this)" class="choice"><span class="false_choice">高く</span>/<span class="true_choice">低く</span></span>なります。
::
---arrow---
::top
加えて、高緯度ほど１月・７月で等温線の値の差が大きくなっています。
::
::middle
1年のうちの最高気温と最低気温の差を「気温の年較差」と言い、気温の年較差は緯度が高くなるほど<span onclick="choice(this)" class="choice"><span class="true_choice">大きい</span>/<span class="false_choice">小さく</span></span>なります。
::
::last
この理由は、地軸のずれによって高緯度ほど１月・７月の入射角の差が大きくなるためです（入射角が大きいほど日光の量が大きい）。

### 大陸と海洋
#### 比熱
::top
気温の気候因子の２つ目は、「大陸と海洋の違い」です。
::
::middle
物質1g当たりの温度を1℃上げるのに必要な熱量を「比熱」と言います。
::
::last
比熱が大きいほど物質は温まりにくく、反対に比熱が小さいほど物質は温まりやすいのです。
::
---arrow---
::top
大陸と海洋のうち、比熱が大きいのは<span onclick="choice(this)" class="choice"><span class="false_choice">大陸</span>/<span class="true_choice">海洋</span></span>です。
::
::middle
つまり==海洋は年中ほぼ一定の温度を保ち（気温の年較差が小さい）、大陸は夏に暑く冬に寒くなります（気温の年較差が大きい）==。
::
::last
なお、このような年較差の特徴は、気温の日較差（１日の最低気温と最高気温の差）にも当てはまります。
::
---arrow---
::top
１月・７月の等温線を比べると、等温線は大陸部分で大きい差があります。
::
::last
比熱の違いがここに表れています。
::
::gazo

::
::gazo
![](isothermal7.webp){.border}

<h4 id="sea_level">隔海度</h4>
::top
{{隔海度|かくかいど}}とは、海からどれだけ離れているかの度合いです。
::
::middle
海から離れるほど、隔海度が「大きい」と表現します。
::
::last
隔海度は、内陸に近づくほど大きくなります。

::
::middle

::
::last
言い換えれば、気温の年較差・日較差は内陸側になるほど<span onclick="choice(this)" class="choice"><span class="true_choice">大きい</span>/<span class="false_choice">小さく</span></span>なります。

## 風
### 上昇気流・下降気流
#### 気流の発生
::top
風についてまず知っておくことは、上昇気流と下降気流についてです。
::
---arrow---
::top
==地表が熱せられると、地表付近の空気が膨張し軽くなって上昇します==。
::
::middle
この上昇する空気の流れを上昇気流と言います。
::
::last
==上昇した空気は、含んでいる水蒸気で雲を形成し、雨を降らせます。==
::
::sup
上昇気流の発生要因は他にもあり
::
::sup
==寒流で空気が冷やされると上昇気流が発生しにくい==
::
::gazo
![](updraft.webp)
上昇気流
::
::top
==上昇した空気が上空で後に冷えると、重くなって下降します==。
::
::middle
この下降する空気のながれを下降気流と言います。
::
::last
==下降気流では雲が形成されにくく、雨が降りません==。
::
::gazo
![](vertical_draft.webp)
下降気流
::

<h5 id="wind">フェーン現象</h5>
::top
風が山脈の斜面を上り反対側に吹き下ろす時、上る側（風上）と吹き下ろす側（風下）で気温が大きく異なる現象を[[フェーン現象]]と言います。
::
::last
アルプス山脈南側から山脈北側に吹き下ろす局地風に由来します。
::
---arrow---
::top
気温の低減率は、100mにつき0.65℃増減しますが、厳密には空気の湿り気で少し変動します。
::
::middle
例えば、山脈を越えた乾いた風が吹き下ろす時、気温の低減率は100mにつき1.0℃増減するようになります。
::
::last
そのため下図のように風上と風下で気温が大きく異なる現象「フェーン現象」が生じるのです。
::
::gazo

## 降水
### 降水の分類
::top
気候要素の１つ「降水」は、成因ごとに次の４つに分かれます。
::
<ul class="en">
<li>対流性降雨:::lead
強い日射で地表の空気が温められ、上昇気流が生じてもたらされる雨
:::
:::lead
熱帯地方の==スコール==など
:::</li>
<li>地形性降雨:::lead
湿った空気が山脈の斜面を上る際にもたらされる雨
:::
:::lead
インド北部に吹き込む==南西季節風==やマダガスカル島東部に吹き込む==南東貿易風==
:::</li>
<li>前線性降雨:::lead
寒気の上に暖気が乗り上げ、上昇気流が生じてもたらされる雨

### 降水量が少ない場所
#### 年間を通じて高気圧に覆われる地域
::top
下降気流が生じているところでは、雲が発生しにくくなります。
::
::last
高気圧に覆われたところは、この下降気流が生じています。
::
---arrow---
::top
年間を通して[[中緯度高圧]]（[[亜熱帯高圧帯]]）帯に覆われる地域は、降水量が少なく、砂漠が形成されます。
::
::gazo
![](subtropical_desert.webp)
亜熱帯砂漠（中緯度砂漠）
::

::gazo
