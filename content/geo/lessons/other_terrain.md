### 氷河
#### 氷河とは？
::top
氷河は、溶けずに残った積雪（万年雪）が自重で圧縮されてできた氷の塊で、岩盤を削りながらゆっくり動きます。
::
::sup
1年に数メートル程度の速度で低位へ移動
::
::gazo
![](glacier_formation.webp)
氷河の形成
::
#### 氷河の種類
::top
氷河には、次の２種類があります。
::
<ul class="en">
<li>大陸氷河:::lead
大陸の全体を広く覆って発達した氷河で、今日は高緯度の南極大陸、デンマーク領グリーンランドのみに分布
:::</li>
<li>山岳氷河:::lead
緯度関係なく、標高の高い山に発達した氷河
:::</li>
</ul>
::gazo
![](ice_sheet.webp)
大陸氷河
*南極大陸
::
::gazo
![](mountain_glacier.webp)
山岳氷河
*アルプス山脈（スイス）のアレッチ氷河
::
#### 今日の大陸氷河
::top
今日、大陸氷河は南極大陸とグリーンランドの２カ所のみです。
::
::middle
約２万年前（最終氷期）には、全陸地の約３分の１、特に高緯度地域が大陸氷河に覆われていました。
::
::last
なお、==カスピ海周辺や冬季に降水量が少ないシベリアは、氷河に覆われていません==。
::
::gazo
![](last_glacial_period.webp){.border}
約２万年前（最終氷期）の大陸氷河
＊中心は北極点
::
### 氷河地形
::top
氷河が移動・融解する時、氷の下や側面の岩盤を削り、また、削ったものを運搬します。
::
::middle
このような働きで形成された地形を、氷河地形と総称します。
::
::last
氷河地形には、主に次の５つがあります。
::
<ul class="en">
<li>[[ホルン]]（[[ホーン]]）
:::lead
周囲を氷河によって削られた岩峰
:::</li>
<li>[[カール]]
:::lead
氷河の侵食によって形成された半円状のくぼ地
:::</li>
<li>[[モレーン]]
:::lead
氷河によって削られた砂礫が氷河の運搬作用によって周縁部に堆積したもの
:::</li>
<li>[[氷河湖]]
:::lead
氷河が削ったくぼ地やモレーンによって形成された湖
:::</li>
<li>[[U]]字谷:::lead
氷河がつくった谷で、谷底は幅が広く平坦
:::</li>
</ul>
::gazo
![](glacial_landform.webp)

## 乾燥地形
### 主な乾燥地形
::top
乾燥気候には、植生がほぼない砂漠や、貴重な水に関連する地形が形成されます。
::
::last
次のものが主な乾燥地形です。
::
<ul class="en">
<li>砂漠:::lead
岩石砂漠・{{礫|れき}}砂漠・砂砂漠に分類
:::
:::lead
砂漠の約9割は[[岩石]]砂漠
:::
:::lead
平坦のように見えるが、==起伏も存在==
:::</li>
<li>[[外来河川]]
:::lead
湿潤地域に源流があり、乾燥地域に流れ込んでいる河川
:::
:::lead
[[ナイル]]川（エジプト）、[[ティグリス]]川（イラク）、[[ユーフラテス]]川（イラク）など
:::</li>
<li>[[ワジ]]
:::lead
降雨時のみ流水が見られる{{涸|か}}れ川
:::</li>
<li>[[オアシス]]
:::lead
外来河川などにより、乾燥地域で局地的に水を得られる場所
:::</li>
<li>塩湖:::lead
蒸発と濃縮により塩分濃度が高い湖沼
:::
:::lead
カスピ海・アラル海・死海・ウユニ塩湖など
:::
<div class="sup">カスピ海は沿岸5か国の利害から、現在は「海」と定義（湖なら資源を共同管理、海なら分割）</div></li>
</ul>

## カルスト地形
### サンゴ礁と石灰岩
::top
石灰岩は、サンゴ礁が堆積して岩石化したものです。
::
::gazo
![](coral_reef_2.webp)
サンゴ礁
::
::gazo
![](limestone.webp)
石灰岩（和歌山県白崎海岸）
::
### カルスト地形とは
::top
石灰岩を含む地層が、二酸化炭素を含む雨水・地下水などに溶食されると、[[カルスト地形]]と総称される地形ができます。
::
::last
この「カルスト」という名は、この地形が発達したスロベニアのカルスト地方に由来します。
::
<sup>石灰岩は水を加えると強固になる性質を持つため、<ruby>漆喰<rt>しっくい</rt></ruby>やセメントに利用</sup>
::gazo
![](Slovenia_karst.webp){.border}
カルスト地方
::
::top
カルスト地形には、主に次のものがあります。
::
<ul class="en">
<li>[[鍾乳洞]]
:::lead
地中の石灰岩が溶食されてできた地下の空洞
:::</li>
<li>[[ドリーネ]]
:::lead
溶食や鍾乳洞の落盤によってできたくぼ地で、特に最小規模のもの
:::</li>
<li>ウバーレ:::lead
ドリーネが拡大・連続してできた長さ１㎞程度のくぼ地
:::</li>
<li>[[ポリエ]]
:::lead
ドリーネやウバーレが拡大・連続してできた大規模なくぼ地
:::</li>
<li>タワーカルスト:::lead
石灰岩の厚い層が高温多雨の気候のもとで溶食を受けてできた岩峰
:::</li>
</ul>
::gazo
![](karst.webp)
カルスト地形
::
::top
カルスト地形の付近には、採取した石灰岩を利用して、[[セメント]]の製造工場がよく立地します。
