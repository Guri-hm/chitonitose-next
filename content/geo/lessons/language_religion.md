#### 地域ごとの食肉の特徴
<h5>ヨーロッパ</h5>
::top
ヨーロッパ諸国（ウクライナ付近含む）は、動物性たんぱく質の多くを肉類から摂取しているため、==１人当たり食料供給量が比較的高くなります==。
::
<h5>中央アジア</h5>
::top
イスラームの信者が多い中央アジア諸国は、教義上の禁忌となっている==豚肉の生産量・消費量が極めて少なくなります==。
::
<h5>日本</h5>
::top
近年食生活の洋風化が進んでいますが、伝統的に畜肉の消費は少なく、たんぱく質の摂取は大豆や魚介類に依存する割合が高いです。
::
::last
==肉類の１人当たり食料供給量は他の先進国に比べて低いです==。
::

## 民族・言語
### 人々の区別
#### 人種
::top
肌の色や毛髪など身体的特徴で人を区別したものが人種です。
::
::last
人種は次の３種類に大別されます。
::
<ul class="en">
<li>モンゴロイド（黄色人種）</li>
<li>コーカソイド（白色人種）</li>
<li>ネグロイド（黒色人種）</li>
</ul>

## 宗教
### 世界宗教と民族宗教
#### 世界宗教
::top
世界宗教とは、人種や民族の枠を超えて信仰されている宗教を指します。
::
::last
例えば、キリスト教・イスラーム・仏教が該当します。
::
#### 民族宗教
::top
民族宗教とは、特定の民族のみに信仰されている宗教を指します。
::
::last
ヒンドゥー教・ユダヤ教・神道・道教が該当します。
::
<div id="religion" class="mx-auto w-100"></div>
### キリスト教
::top
キリスト教はユダヤ教から派生し、イエスが創始した宗教です。
::
#### 基礎知識
::top
聖典：<div class="top">旧約聖書（ユダヤ教の聖典）・新約聖書
::
</div>
::top
聖地：<div class="top">エルサレム
::
</div>
#### ３つの宗派
::top
キリスト教は次の３つの宗派に大きく分かれます。
::
<ul class="en">
::top
南ヨーロッパや中・南アメリカ
::
::top
北・西ヨーロッパ
::
<li>東方正教：東ヨーロッパやロシア</li>
</ul>
<div class="arrow">カトリックの教えでは避妊・中絶が好ましくないこととされます。</div>
::last
アメリカに移民したヒスパニック系にはカトリックが多く、多産傾向となります。
::
### イスラーム
::top
ムハンマドが創始した宗教です。
::
#### 基礎知識
::top
聖典：<div class="top">コーラン
::
</div>
::top
聖地：<div class="top">メッカ・メディナ・エルサレム
::
</div>
::top
禁忌<div class="top">飲食（豚・酒）、人前での女性の肌の露出
::
</div>
::top
暦<div class="top">太陰暦（月の満ち欠けが周期）
::
</div>
<h5>豚</h5>
::top
イスラーム教徒（ムスリム）が多い国では、豚の飼育が少なくなります。
::
<h5>女性</h5>
::top
イスラーム教徒が多い国では女性の地位が低く、社会進出が遅れています。
::
#### ２つの宗派
::top
イスラームは次の２つの宗派に大きく分かれます。
::
<ul class="en">
::top
多数派で、西アジアや北アフリカで多い
::
::top
少数派で、イランやアゼルバイジャンで多い
::
</ul>
### 仏教
::top
釈迦（ブッダ）が創始した宗教です。
::
::last
仏教では、悟りを開き、「仏」になることが目指されます。
::
#### ２つの宗派
::top
仏教は悟りを開く方法で次の宗派にわかれます。
::
<ul class="en">
::top
教えを広め、多くの人を救済していくなかで悟りを開くことが目的
::
::top
個人が修業して悟りを開くことが目的
::
</ul>
::sup
ラマ教<div class="lead">チベットに伝来した仏教が現地の民族宗教と混合
::
</div>
### ヒンドゥー教
::top
古代インドのバラモン教から派生した宗教です。
::
#### 基礎知識
::top
禁忌：飲食（牛）
::
::top
聖地：<div class="top">ヴァラナシ
::
</div>
::sup
牛<div class="lead">シヴァという神の乗り物であり、聖なる動物
::
</div>
#### カースト制度
::top
カースト制度と呼ばれる社会制度があり、ヒンドゥー教徒は生まれながらにして定まった社会集団の一員として生きていきます。
::
::last
職業・結婚・職業などを別の社会集団とともにしないという習慣が、現在も根強く残っています。
::
