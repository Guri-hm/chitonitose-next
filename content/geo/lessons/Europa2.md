## 国家群
::top
第二次世界大戦の要因には、次のことがあげられます。
::
<ul class="en">
<li>高関税による保護貿易</li>
<li>ドイツ・フランスの資源をめぐる対立</li>
</ul>
::last
大戦後、ヨーロッパの統合を目指す国家群の形成が進みました。
::
### EU・EFTAの歩み
#### ECSC・EEC・EURATOM・EC
::top
[[ドイツ]]・[[フランス]]・[[イタリア]]・ベネルクス３国（[[ベルギー]]・[[オランダ]]・[[ルクセンブルク]]）の６ヵ国で、ヨーロッパ統合のための国家群が形成されました。
::
<ul class="en">
<li>1952年、ECSC（ヨーロッパ石炭鉄鋼共同体）:::lead
西ヨーロッパで石炭・鉄鋼の生産の共同管理を目指す国家群
:::</li>
<li>1958年、EEC（ヨーロッパ経済共同体）:::lead
西ヨーロッパで経済的な国境の解消を目指す（最終的には政治・外交の共通化も目指す）国家群
:::</li>
<li>1958年、EURATOM（ヨーロッパ原子力共同体）:::lead
西ヨーロッパで原子力の共同開発と管理を目指す国家群
:::</li>
</ul>
---arrow---
::top
1967年、EC（ヨーロッパ共同体）<div class="lead">ECSC・EEC・EURATOMが統合され、新たに結成された国家群
::
</div>
#### EU
::top
1989年、ベルリンの壁崩壊とともに冷戦が終わりました。
::
::last
ヨーロッパにおける安全保障の環境が大きく変化し、ECはより一層結束を強めていく必要がありました。
::
---arrow---
::top
1993年、EU（ヨーロッパ共同体）<div class="lead">マーストリヒト条約締結により、ECを基礎に新たに結成された国家群
::
<div class="lead">EUの運営を担う主要機関は<span class="marker">複数の国に分散</span>（本部はベルギーのブリュッセル）</div>
</div>
---arrow---
::top
EUは、EFTAの脱退国や旧ソ連の東ヨーロッパ諸国を加えて拡大してきました。
::
::middle
2020年、イギリスは移民の流入を嫌ってEUを離脱しました。
::
::last
2020年現在、EUには27ヵ国が加盟しています。
::
::sup

### EUの諸機関・諸政策
#### 欧州議会
::top
欧州議会は、EUの運営について討議する議会です。
::
::last
欧州議会の本会場は、フランスのストラスブールにあります。
::
::sup
ストラスブール
		<div class="lead">フランス東部のアルザス地方の中心地で、ドイツとの国境沿いに位置し、同地方・ロレーヌ地方で産出する石炭・鉄鉱石をめぐって==両国が過去に幾度も対立==
::
<div class="lead">欧州議会の本会場を設置した理由は、ヨーロッパの平和の実現を目指してのこと</div>
</div>
::gazo
![](map_Strasbourg.webp){.border}
ストラスブール
::
#### シェンゲン協定
::top
シェンゲン協定は、協定への加盟国間で、国境検査なし（パスポート検査なし）での移動を許可する協定です。
::
#### ユーロ
::top
ユーロ（€）は、EUで導入した単一通貨であり、ユーロ加盟国内で使用できます。
::
::last
加盟国は、欧州中央銀行の金融政策に従う必要があります。
::
::sup
欧州中央銀行<div class="lead">ユーロ通貨圏の金融政策を担う中央銀行で、本部はドイツの[[フランクフルト]]
::
</div>

::
::last

#### 農業政策
::top
EUの基本的な農業政策は、共通農業政策と呼ばれています。
::
<h5>域内の流通</h5>
::top
EUでは、関税を撤廃したことで、生産性の高い国の農産物（安価な農産物）が出回ります。
::
::last
生産性の低い国の農産物が売れないため、生産性が低い国の価格にあわせて域内統一価格を設定します。
::
::gazo
![](cap_intra.webp){.twice}
共通農業政策（域内）
::
::top
上図の仕組みでは、補助金を頼りにした生産過剰に陥りやすく、EUの財政負担が増すばかりでした。
::
::last
現在では、域内統一価格の基準を引き下げ、赤字を出した農家には補助金を出すように転換しました。
::
::gazo
![](cap_intra2.webp)
共通農業政策（域内）
::
<h5>域外との貿易</h5>
::top
安価な農産物の輸入は、域内の農産物の売れ行きに影響します。
::
::middle
EUでは、輸出入時に価格を調節するようにしています。
::
::last
この取り組みは、域外の国から「保護貿易」と非難を受けています。
::
::gazo
![](cap_outsidepng.webp){.twice}
共通農業政策（貿易）

## 農業
### 農業の歴史
#### 古代
::top
古代は、地力の消耗を防ぐために、収穫後は一年休閑させました。
::
::last
土地を２つにわけ、一方を耕作、他方を休閑としたので、二圃式と呼ばれています。
::
#### 中世
::top
二圃式は効率が悪いため、土地を３つにわけ、うち２つを耕作、残りを休閑とする三圃式に変化しました。
::
::last
やがてカブやクローバーに地力を回復させる効果があるとわかり、休耕地ではその栽培と放牧をするようになりました。
::
#### 現代
::top
現在のヨーロッパの農業形態は、二圃式・三圃式が変化し、次の４分類ができたと考えられています。
::
<ul class="en">
<li>[[混合農業]]（ドイツ・フランスなど）</li>
<li>酪農（イギリス・デンマーク・オランダなど）</li>
<li>園芸農業（オランダなど）</li>
<li>地中海式農業（イタリア・スペインなど）</li>
</ul>
::gazo
![](European_agriculture_changes.webp){.twice}
ヨーロッパの農業形態の変遷
